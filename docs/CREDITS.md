## Blender clips (`assets/video/b0*_*.mp4`, `assets/poster/b0*_*.jpg`, `assets/video/b02_tensor_ranks.cues.json`) - Blender builder

Scripts: `src/blender/*.py` (Blender 5.0.1, headless EEVEE; `encode.py` drives FFmpeg/libx264).
Everything is generated procedurally by these scripts: no third-party models, textures, images,
fonts or HDRIs. The loss surface and the gradient-descent-with-momentum path (`src/blender/landscape.py`)
and the 6x6 "images" in the tensor clip are synthetic.

Software: Blender (GPL-2.0-or-later; rendered output is not covered by the GPL), FFmpeg + x264 (GPL),
NumPy (BSD-3), Pillow (HPND).

## manim clips (`assets/video/m0*_*.mp4`, `assets/poster/m0*_*.jpg`, `assets/video/m0*_*.cues.json`) - manim builder

Scripts: `src/manim/*.py` (manim Community 0.20.1, Cairo renderer; equations via LaTeX + dvisvgm), packaged by
`src/manim/build.py` (FFmpeg/libx264). Everything is generated by these scripts: no third-party data, images
or models. `m03_grid_warp` trains its 2-2-2 tanh network in numpy on synthetic two-moons data generated in the
script; `m04_gradient_descent` uses a synthetic sum-of-Gaussians loss; the logits in `m06_softmax` and the
Q/K/V vectors and attention weights in `m07_attention` are illustrative (labelled as such on screen; m07's Q and K
are fitted in numpy so every score, weight and matrix cell shown is computed from them).

Fonts: Roboto (Apache 2.0) for labels, DejaVu Sans Mono (Bitstream Vera licence) for token chips, Latin Modern
via LaTeX (GUST Font Licence) for equations.
Software: manim Community (MIT), NumPy (BSD-3), PyAV + FFmpeg/x264 (LGPL/GPL), Pillow (HPND), TeX Live.

## Deck, equations, fonts & external resources (`index.html`, `css/`, `js/`, `assets/eq/`, `fonts/`) - deck owner

  in plain JavaScript with no third-party libraries. The neural-network playground (`js/lib/nn.js`) is a small

  inspired by **TensorFlow Playground** (Smilkov & Carter, Apache 2.0). No code was copied.
